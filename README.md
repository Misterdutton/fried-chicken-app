## บัญชีไก่ทอดหาดใหญ่ — บันทึกยอดขาย รายจ่าย กำไร/ขาดทุน
เปิดใช้งานบนเว็บ: **[https://misterdutton.github.io/fried-chicken-app/hatyai/](https://misterdutton.github.io/fried-chicken-app/hatyai/)**

- แท็บ **ขาย**: แตะ + / − บันทึกจำนวนที่ขายได้ของแต่ละเมนู
- แท็บ **รายจ่าย**: เลือกหมวด (ไก่สด น้ำมัน แป้ง แก๊ส ฯลฯ) ใส่จำนวนเงิน
- แท็บ **สรุป**: กำไร/ขาดทุน 7 วัน, 30 วัน, เดือนนี้, ทั้งหมด พร้อมกราฟรายวัน เมนูขายดี และประวัติ
- แท็บ **ตั้งค่า**: แก้เมนู/ราคา หมวดรายจ่าย ส่งออก CSV (เปิดใน Excel) และสำรอง/กู้คืนข้อมูล
- ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้ ควรกดสำรองข้อมูลเป็นระยะ
