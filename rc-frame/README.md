# RC Frame 8

โปรแกรมวิเคราะห์และออกแบบโครงข้อแข็งคอนกรีตเสริมเหล็ก 2 มิติ สำหรับอาคารสูงไม่เกิน 8 ชั้น ทำงานในเว็บเบราว์เซอร์ ไม่ต้องติดตั้ง

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ (ใช้ร่วมกับ `engine.js` ในโฟลเดอร์เดียวกัน) กรอกข้อมูลแล้วผลจะคำนวณใหม่อัตโนมัติ

## ความสามารถ
- วิเคราะห์ด้วยวิธี Direct Stiffness (3 DOF/จุดต่อ ฐานยึดแน่น) ใช้สติฟเนสหน้าตัดร้าว คาน 0.35Ig เสา 0.70Ig
- น้ำหนักบรรทุก D, L (พื้น/หลังคา/ผนัง + น้ำหนักคานและเสา) และแรงแผ่นดินไหวแบบสถิตเทียบเท่าตาม มยผ.1301/1302-61
  (Ta = 0.02H, Cs, การกระจายแรงตามความสูงด้วย k, ระบบ OMF/IMF/SMF)
- Load combination ตาม ACI 318-19 รวมแรงแผ่นดินไหวแนวดิ่ง 0.2SDS·D: 1.4D, 1.2D+1.6L, (1.2+0.2SDS)D+1.0L±1.0E, (0.9−0.2SDS)D±1.0E
- คำนวณประเภทการออกแบบต้านทานแผ่นดินไหว (ก/ข/ค/ง) และเตือนเมื่อเลือกระบบโครงสร้างที่ไม่อนุญาต
- ตรวจ story drift (Cd·δxe/Ie ≤ 0.020h) และสัมประสิทธิ์เสถียรภาพ θ (P-Delta)
- ออกแบบคาน: เหล็กบน/ล่างรับโมเมนต์ และเหล็กปลอกรับแรงเฉือน
- ออกแบบเสา: interaction diagram P–M, ρg 1–8%, เหล็กปลอก
- แผนภาพ: ผลตรวจสอบ (อัตราส่วนใช้งาน), การเสียรูป, BMD, SFD, AFD ทุก combo หรือ envelope

## ไฟล์
- `engine.js` ส่วนคำนวณ (ใช้ได้ทั้งในเบราว์เซอร์และ Node.js)
- `index.html` หน้าจอผู้ใช้
- `test/engine.test.js` ชุดทดสอบเทียบกับสูตรคำนวณมือ: `node rc-frame/test/engine.test.js`

## ข้อจำกัด
ยังไม่รวมแรงลม (มยผ.1311-50), สเปกตรัมแอ่งกรุงเทพฯ, เสารับโมเมนต์สองทาง, capacity design ของ IMF/SMF, แรงบิดโดยบังเอิญ, ผลแนวดิ่งของแผ่นดินไหว, ความชะลูดของเสา, strong column–weak beam,
ข้อกำหนดรายละเอียดเหล็กเสริมด้านความเหนียว, จุดต่อคาน–เสา และฐานราก
ผลลัพธ์ใช้ประกอบการออกแบบเบื้องต้น งานจริงต้องให้วิศวกรโยธาที่มีใบอนุญาตตรวจสอบและรับรอง
